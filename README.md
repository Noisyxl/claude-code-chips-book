# Claude Code Chips Book

An unofficial 3D pop-up book about Claude Code agents, the chips they run on, and how to keep the token bill small.

**Open it:** https://noisyxl.github.io/claude-code-chips-book/

- 5 lessons: Token jars · Agent chips · Pick the right chip · Squeeze the context · The crew
- Tap the pop-up scenes, predict, lift the flap, press ▶ for a guided tour
- Pencil-hatched three.js scenes, pixel agents rebuilt in 3D

Prices and cost tips come from the Claude API pricing page and the Claude Code docs (Haiku / Sonnet / Opus 5.5). Check current pricing before you budget.

## Edit
The source is `src/book.html` (the cover mascot is `sprites/base.png`). Rebuild with `python3 build.py`, which writes `index.html`.
